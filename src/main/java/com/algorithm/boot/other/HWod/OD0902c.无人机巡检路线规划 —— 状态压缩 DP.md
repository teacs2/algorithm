# 无人机巡检路线规划 —— 状态压缩 DP

## 1. 题目描述

无人机从基地 `(0,0)` 出发，需要访问所有电力塔。

每个电力塔坐标为：

```text
(xi, yi)
```

两个位置之间的距离使用曼哈顿距离：

```text
|x1 - x2| + |y1 - y2|
```

要求：

- 每个电力塔都需要访问
- 访问顺序可以任意
- 最后不需要返回基地
- 求最短总飞行距离

数据范围：

```text
1 <= n <= 15
```

---

# 2. 最直接的思路：暴力 DFS

假设有三个塔：

```text
A
B
C
```

所有可能访问顺序：

```text
O -> A -> B -> C
O -> A -> C -> B
O -> B -> A -> C
O -> B -> C -> A
O -> C -> A -> B
O -> C -> B -> A
```

所以最直接的方法就是：

```text
枚举所有排列
→ 计算每条路径长度
→ 找最小值
```

但是复杂度是：

```text
O(n!)
```

当：

```text
n = 15
```

时：

```text
15! ≈ 1.3 万亿
```

无法接受。

---

# 3. 为什么可以使用动态规划

假设已经访问：

```text
A、B、C
```

当前停在：

```text
C
```

之前可能是：

```text
O -> A -> B -> C
```

也可能是：

```text
O -> B -> A -> C
```

但是对于接下来怎么走来说，之前的具体顺序已经不重要了。

未来只需要知道：

```text
1. 哪些塔已经访问
2. 当前停在哪个塔
```

所以一个状态可以表示为：

```text
(mask, curr)
```

其中：

```text
mask
```

表示哪些塔已经访问。

```text
curr
```

表示当前停在哪个塔。

---

# 4. mask 状态压缩

假设有三个塔：

```text
0 -> A
1 -> B
2 -> C
```

使用二进制表示访问状态：

```text
000 -> 一个都没有访问
001 -> 访问 A
010 -> 访问 B
011 -> 访问 A、B
100 -> 访问 C
101 -> 访问 A、C
110 -> 访问 B、C
111 -> 全部访问
```

例如：

```java
int mask = 5;
```

二进制：

```text
101
```

表示：

```text
A 已访问
B 未访问
C 已访问
```

# 5. 常用位运算

## 判断某个塔是否已经访问

```java
(mask & (1 << i)) != 0
```

例如：

```java
if ((mask & (1 << next)) != 0) {
    continue;
}
```

表示：

```text
next 已经访问过，跳过
```

---

## 将某个塔加入访问集合

```java
mask | (1 << i)
```

例如：

```java
int newMask = mask | (1 << next);
```

注意：

```java
&
```

是判断。

```java
|
```

是加入。

可以记：

```text
判断有没有：&
添加进去：|
```

# 6. 方法一：DFS + 记忆化搜索

这个方法更符合人的正常思考方式，建议先理解这个。

---

## 6.1 DFS 状态定义

定义：

```java
dfs(mask, curr)
```

表示：

```text
当前已经访问了 mask 中的塔，
现在停在 curr，
把剩余所有塔访问完，
还需要走的最短距离。
```

注意：

```text
dfs 返回的是“未来还需要走多少距离”
```

而不是：

```text
当前已经走了多少距离
```

---

# 7. DFS 状态转移

假设现在：

```text
当前在 curr
```

选择下一个塔：

```text
next
```

那么总成本为：

```text
curr -> next 的距离
+
从 next 开始访问剩余所有塔的最短距离
```

也就是：

```java
distance[curr][next]
+
dfs(newMask, next)
```

所以：

```java
ans = Math.min(
        ans,
        distance[curr][next]
                + dfs(newMask, next)
);
```

---

# 8. DFS 终止条件

如果所有塔都已经访问：

```java
if (mask == (1 << n) - 1) {
    return 0;
}
```

因为：

```text
已经全部访问完
后面不需要再走
并且不需要返回基地
```

所以返回：

```text
0
```

# 9. DFS + 记忆化完整代码

```java
package com.algorithm.boot.other.HWod;

import java.util.Arrays;

public class OD0902c {

    /**
     * 方法一：
     * DFS + 记忆化搜索
     */
    public int minDistanceMemo(int[][] towers) {
        if (towers == null || towers.length == 0) {
            return 0;
        }

        int n = towers.length;

        // 预处理塔与塔之间的曼哈顿距离
        int[][] distance = new int[n][n];

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {

                int dist =
                        Math.abs(towers[i][0] - towers[j][0])
                                + Math.abs(towers[i][1] - towers[j][1]);

                distance[i][j] = dist;
                distance[j][i] = dist;
            }
        }

        // memo[mask][curr]
        //
        // 当前访问状态为 mask，
        // 当前停在 curr，
        // 访问完剩余所有塔还需要的最短距离
        int[][] memo = new int[1 << n][n];

        for (int[] row : memo) {
            Arrays.fill(row, -1);
        }

        int ans = Integer.MAX_VALUE;

        // 枚举第一个访问的塔
        for (int i = 0; i < n; i++) {

            // 基地 (0,0) -> 第 i 个塔
            int startDistance =
                    Math.abs(towers[i][0])
                            + Math.abs(towers[i][1]);

            // 第 i 个塔已经访问
            int mask = 1 << i;

            ans = Math.min(
                    ans,
                    startDistance
                            + dfs(mask, i, towers, distance, memo)
            );
        }

        return ans;
    }

    /**
     * 当前已经访问 mask 中的塔，
     * 当前停在 curr，
     * 访问完剩余所有塔需要的最短距离
     */
    private int dfs(
            int mask,
            int curr,
            int[][] towers,
            int[][] distance,
            int[][] memo) {

        int n = towers.length;

        // 所有塔都已经访问
        if (mask == (1 << n) - 1) {
            return 0;
        }

        // 当前状态以前计算过
        if (memo[mask][curr] != -1) {
            return memo[mask][curr];
        }

        int ans = Integer.MAX_VALUE;

        // 尝试访问下一个塔
        for (int next = 0; next < n; next++) {

            // next 已经访问
            if ((mask & (1 << next)) != 0) {
                continue;
            }

            // 把 next 加入已访问集合
            int newMask = mask | (1 << next);

            // 当前选择代价
            // +
            // 剩余问题最优解
            int cost =
                    distance[curr][next]
                            + dfs(
                                    newMask,
                                    next,
                                    towers,
                                    distance,
                                    memo
                            );

            ans = Math.min(ans, cost);
        }

        // 记住“当前状态”的答案
        memo[mask][curr] = ans;

        return ans;
    }
}
```

# 10. DFS 的核心模板

记忆化 DFS 可以抽象成：

```java
dfs(状态) {

    if (到达终点) {
        return 0;
    }

    if (memo[状态] 已经计算) {
        return memo[状态];
    }

    int ans = INF;

    for (所有可以做的选择) {

        ans = Math.min(
                ans,
                当前选择代价
                        + dfs(新状态)
        );
    }

    memo[状态] = ans;

    return ans;
}
```

这道题对应：

```text
状态：
mask + curr

选择：
下一个未访问的塔 next

当前选择代价：
distance[curr][next]

新状态：
newMask + next
```

# 11. 我容易写错的地方

## 错误 1：newMask 使用了 &

错误：

```java
int newMask = mask & (1 << next);
```

正确：

```java
int newMask = mask | (1 << next);
```

例如：

```text
mask        = 0101
1 << next   = 0010
```

如果使用：

```text
&
```

得到：

```text
0101
0010
----
0000
```

状态反而丢失了。

使用：

```text
|
```

得到：

```text
0101
0010
----
0111
```

表示：

```text
在原来的访问状态上，又访问了 next
```

所以记：

```text
检查状态：&
增加状态：|
```

---

## 错误 2：忘记计算 curr -> next 的距离

错误：

```java
ans = Math.min(
        ans,
        dfs(newMask, next, towers, distance, memo)
);
```

这里漏掉：

```text
curr -> next
```

正确：

```java
ans = Math.min(
        ans,
        distance[curr][next]
                + dfs(newMask, next, towers, distance, memo)
);
```

本质：

```text
当前选择的代价
+
剩余问题的最优解
```

即：

```text
A -> B -> 后面的路径
```

应该是：

```text
A -> B 的距离
+
从 B 开始的最优路径
```

---

## 错误 3：memo 存到了子状态

错误：

```java
memo[newMask][next]
        = memo[mask][curr]
        + distance[curr][next];
```

实际上：

```java
dfs(mask, curr)
```

正在负责计算的是：

```text
memo[mask][curr]
```

所以应该：

```java
memo[mask][curr] = ans;
```

然后：

```java
return ans;
```

每一个递归函数只负责自己的状态。

即：

```text
dfs(mask, curr)
只负责
memo[mask][curr]
```

而：

```text
dfs(newMask, next)
```

会自己负责：

```text
memo[newMask][next]
```

```text
dfs(mask, curr)

        │
        ├── 选择 next1
        │
        │   distance[curr][next1]

                ↓

             return ans
```

# 13. 方法二：迭代状态压缩 DP

这个就是最开始的标准状态压缩 DP 写法。

状态：

```java
dp[mask][i]
```

表示：

```text
已经访问 mask 中的所有塔，
最后停在第 i 个塔，
此时从基地出发的最短总距离。
```

注意它和 DFS 的定义稍微不同。

DFS：

```text
dfs(mask, curr)
=
从当前状态开始，
未来还需要走多少
```

DP：

```text
dp[mask][curr]
=
从基地出发，
到达当前状态已经走了多少
```

# 14. DP 初始化

一开始直接从：

```text
基地 (0,0)
```

飞到：

```text
第 i 个塔
```

所以：

```java
dp[1 << i][i] =
        Math.abs(towers[i][0])
                + Math.abs(towers[i][1]);
```

例如：

```text
A = (1,2)
```

那么：

```text
O -> A = 3
```

所以：

```text
dp[001][A] = 3
```

# 15. DP 状态转移

假设：

```java
dp[mask][i]
```

已经计算出来。

当前：

```text
已经访问 mask 中的塔
现在停在 i
```

选择一个未访问的：

```text
j
```

则：

```java
newMask = mask | (1 << j);
```

新的距离：

```text
之前已经走的距离
+
i -> j 的距离
```

也就是：

```java
dp[mask][i] + distance[i][j]
```

所以：

```java
dp[newMask][j] =
        Math.min(
                dp[newMask][j],
                dp[mask][i] + distance[i][j]
        );
```

# 16. 迭代状态压缩 DP 完整代码

```java
package com.algorithm.boot.other.HWod;

import java.util.Arrays;

public class OD0902c {

    /**
     * 方法二：
     * 状态压缩 DP
     */
    public int minDistanceDp(int[][] towers) {

        if (towers == null || towers.length == 0) {
            return 0;
        }

        int n = towers.length;

        // 预处理任意两个电力塔之间的曼哈顿距离
        int[][] distance = new int[n][n];

        for (int i = 0; i < n; i++) {

            for (int j = i + 1; j < n; j++) {

                int dist =
                        Math.abs(towers[i][0] - towers[j][0])
                                + Math.abs(towers[i][1] - towers[j][1]);

                distance[i][j] = dist;
                distance[j][i] = dist;
            }
        }

        // 一共有 2^n 种访问状态
        int stateCount = 1 << n;

        /**
         * dp[mask][i]
         *
         * 已经访问 mask 中的塔，
         * 当前最后停在第 i 个塔，
         * 从基地出发到当前状态的最短距离
         */
        int[][] dp = new int[stateCount][n];

        int inf = Integer.MAX_VALUE / 2;

        for (int[] row : dp) {
            Arrays.fill(row, inf);
        }

        // 初始化
        //
        // 从基地 (0,0)
        // 直接访问第 i 个塔
        for (int i = 0; i < n; i++) {

            dp[1 << i][i] =
                    Math.abs(towers[i][0])
                            + Math.abs(towers[i][1]);
        }

        // 枚举所有访问状态
        for (int mask = 0; mask < stateCount; mask++) {

            // 枚举当前停在哪个塔
            for (int i = 0; i < n; i++) {

                // 当前状态根本没有访问 i
                if ((mask & (1 << i)) == 0) {
                    continue;
                }

                // 当前状态没有被更新过
                if (dp[mask][i] == inf) {
                    continue;
                }

                // 尝试访问下一个塔 j
                for (int j = 0; j < n; j++) {

                    // j 已经访问
                    if ((mask & (1 << j)) != 0) {
                        continue;
                    }

                    // 加入 j
                    int newMask =
                            mask | (1 << j);

                    // 状态转移
                    dp[newMask][j] =
                            Math.min(
                                    dp[newMask][j],
                                    dp[mask][i]
                                            + distance[i][j]
                            );
                }
            }
        }

        // 全部塔都已经访问
        int fullMask = stateCount - 1;

        int ans = inf;

        // 最后停在哪个塔都可以
        //
        // 因为不要求返回基地
        for (int i = 0; i < n; i++) {
            ans = Math.min(
                    ans,
                    dp[fullMask][i]
            );
        }

        return ans;
    }
}
```

# 18. DFS 和 DP 最大的区别

## DFS + 记忆化

思考方向：

```text
我想知道当前问题的答案

↓

去问子问题

↓

子问题继续往下问

↓

最终返回答案
```

属于：

```text
自顶向下
```

例如：

```text
dfs(当前)
    ↓
dfs(下一步)
    ↓
dfs(下一步)
    ↓
终点
```

---

## 迭代 DP

思考方向：

```text
我已经知道小状态

↓

看看它可以推出哪些大状态

↓

不断扩展

↓

最终得到完整状态
```

属于：

```text
自底向上
```

# 19. 两种状态定义的区别

这个地方非常重要。

## DFS

```java
dfs(mask, curr)
```

表示：

```text
从当前状态开始，
访问完剩余所有塔，
未来还需要走的最短距离。
```

因此：

```java
distance[curr][next]
+
dfs(newMask, next)
```

---

## DP

```java
dp[mask][curr]
```

表示：

```text
从基地出发，
访问了 mask 中的塔，
最后停在 curr，

```

因此：

```java
dp[mask][curr]
+
distance[curr][next]
```

```java
dp[newMask][next]
```

# 20. 为什么 n <= 15 是重要提示

状态数量：

```text
2^n
```

当：

```text
n = 15
```

时：

```text
2^15 = 32768
```

状态压缩 DP 时间复杂度：

```text
O(2^n * n^2)
```

大约：

```text
32768 × 15 × 15
≈ 737 万
```

完全可以接受。

而暴力排列：

```text
O(n!)
```

当：

```text
n = 15
```

时：

```text
15!
≈ 1.3 万亿
```

无法接受。


# 22. 最核心的理解

不要一开始把：

```java
dp[mask][i]
```

理解成一个很抽象的动态规划公式。

可以先想：

```text
DFS 本来需要：

visited
+
当前位置 curr
```

普通 DFS：

```java
boolean[] visited;
dfs(curr);
```

状态压缩只是把：

```java
boolean[] visited
```

压缩成了：

```java
int mask
```

于是：

```text
visited + curr
```

变成：

```text
mask + curr
```

然后再加：

```java
memo[mask][curr]
```

避免重复计算。

所以：

```text
DFS + visited
        ↓
DFS + mask
        ↓
DFS + mask + memo
        ↓
记忆化搜索
        ↓
转换成二维 dp
        ↓
状态压缩 DP
```

这就是整个演化过程。

# 24. 一句话总结

这道题的本质不是记住复杂的 `dp[mask][i]`。

而是：

```text
当前问题只取决于：

1. 哪些节点已经访问
2. 当前在哪个节点
```

因此：

```text
状态 = mask + curr
```

再利用：

```text
当前选择代价
+
剩余问题最优解
```

就可以从暴力 DFS 推导出：

```text
DFS
→ 记忆化搜索
→ 状态压缩 DP
```
